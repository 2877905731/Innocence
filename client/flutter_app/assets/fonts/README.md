# 侘寂展示字体

应用离线打包以下字体，供 Windows、Android、HarmonyOS 共用；不依赖系统 Georgia 或浏览器字体下载。正文与表单继续使用原平台字体。

- Crimson Text Regular / Italic：英文标题和错位斜体品牌字。
  来源：<https://github.com/google/fonts/tree/main/ofl/crimsontext>。
- Noto Serif SC Variable：中文标题、印章及英文展示字的中文回退。
  来源：<https://github.com/google/fonts/tree/main/ofl/notoserifsc>。

字体文件为上游原件，未裁剪或修改。各目录内 `OFL.txt` 保留版权和 SIL Open Font License 1.1，并作为应用资源打包。完整中文字体约 25 MB，保留所有上游字形以覆盖用户输入的中文标题。
