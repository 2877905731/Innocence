# Innocence v1.2.3

更新简约白页面、专注表盘和 Android 专注布局，Windows 增加自带 Key 的聊天助手。版本为 `1.2.3+8`。

## 更新内容

- 简约白按黑白灰重建，使用 INN/CNCE 字体标识、白色直角面板、浅灰画布和细线进度。
- 首页与专注页复用真实计时表盘，暂停冻结、继续、结束和每日标语保持会话逻辑；Android 数字与表盘合组、通栏动作、窄屏和大字体重排。
- Windows 聊天助手支持地址与 Key 获取模型、选择并验证连接、Chat Completions/Responses 和多轮对话。14 项工具覆盖受限计划新增/撤销、存档、备忘录、年度新任务/子任务、专注与导航设置，具体写动作经确认执行。当前账号或本机身份的连接配置经用户级 DPAPI 保存；真实供应商和完整工具范围仍待验收。
- 本机 SQLite 升级至 v6，保留已有资料域、任务标识和历史数据；新增助手提案、执行记录与单日修订。
