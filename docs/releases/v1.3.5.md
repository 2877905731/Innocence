# Innocence v1.3.5 · 三端任务手动排序

应用版本 **1.3.5+17**，Windows x64 与 Android 联网版。鸿蒙平板见 [v1.3.5-harmonyos.1](https://github.com/2877905731/Innocence/releases/tag/v1.3.5-harmonyos.1)。

## 更新内容

- 今日计划新增“排序”，固定时段任务和灵活任务可以混合调整清单顺序；拖动手柄或使用上移、下移箭头，再保存。
- 年度任务及年度子任务均支持排序。年度按月筛选共用全年顺序，编辑器中的任务草稿和子任务也可以调整顺序。
- 排序只改变清单顺序，保留任务时段、完成状态、实际学习时长及年度月份、颜色、进度和子任务内容。今日编辑器再次保存不会恢复时间顺序；时间轴仍按原时段绘制。
- 离线重启后保留顺序；在线排序校验当前账号、完整任务集合和版本，遇到其他设备已修改的计划会拒绝覆盖。保存失败保留排序草稿。

- [SHA256 校验清单](https://github.com/2877905731/Innocence/releases/download/v1.3.5/SHA256SUMS.txt)

在线账号可在“设置 → 关于与维护 → 软件更新”检查更新。保留原应用和数据，直接覆盖；Android沿用原发行证书。Windows安装器仍没有Authenticode发布者签名，下载完整性按SHA256校验。1.3.3及更早版本没有应用内更新入口，需要手动下载覆盖。

鸿蒙公开文件为未签名ARM64 HAP，需有效证书及设备Profile由电脑签名覆盖，不能直接点击安装。离线资料仍经导入预览和目标账号确认后上传，不因本次更新自动绑定。
