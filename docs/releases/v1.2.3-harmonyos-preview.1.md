# Innocence v1.2.3 鸿蒙平板开发预览 1

这是单独发布的未签名 Debug HAP 开发预览，应用版本为 `1.2.3+8`。**ARM64 包不能直接安装到华为实体平板，必须先配置设备调试 Profile 并签名。** 本次为 GitHub 预览分发，不是华为应用市场上架，也不是已经完成真机验收的正式版。

| 文件 | 使用对象 |
|---|---|
| `Innocence-v1.2.3-harmonyos-arm64-debug-unsigned.hap` | ARM64 鸿蒙平板开发调试；签名后才可部署到实体设备 |
| `Innocence-v1.2.3-harmonyos-x64-emulator-debug-unsigned.hap` | DevEco x64 平板模拟器；不能用于 ARM64 平板 |
| `HARMONYOS-PREVIEW-README.md` | 本说明的离线副本 |
| `SHA256SUMS.txt` | 两个 HAP 和离线说明的 SHA-256 校验清单 |

平板复用 PC 页面与四主题，横屏/反向横屏全屏启动，关闭 Windows 窗口控制、拖边、托盘与 Focus Orb。当前客户端强制本机模式，登录、同步及模型联网调用未开放；Debug 模板仍声明 INTERNET 权限，因此不能称作无网络权限的离线正式包。

本轮两个 HAP 的完整原生编译、ZIP CRC、版本号、目标 API 26/兼容 API 18、对应架构的 Flutter/SQLite ELF、图标和各 113 个共享 Dart 文件一致性已经核对。兼容 API 下限来自模板，不代表所有 API 18 设备已经运行验证。

此前 `1.2.2+7` 的 x64 包已在 HarmonyOS 7/API 26 平板模拟器安装启动，观察到 PC 全屏首页和四主题、Preferences 进程冷启动恢复、SQLite 初始 schema v6。本次 `1.2.3+8` x64 HAP 已通过 HDC 在同类 API 26/x64 模拟器安装、启动及进程冷启动复验：系统包信息为 `1.2.3+8`，应用全屏范围 `[0,0][2800,1840]`，原生截图可见简约白 PC 首页。仅针对该进程的日志筛选未命中 Flutter 致命异常或 RenderFlex 溢出，仍出现 2 条输入法 `12800008/12800009`。**实体 ARM64 平板签名、安装、覆盖升级及业务数据恢复仍未验证。** 小艺输入法首次协议需用户处理，玻璃编辑黑屏/输入法服务错误、业务资料保存与冷启动恢复、完整触控、文件选择、HUKS 和设备槽位契约仍待验收。

## 构建与设备签名

1. 获取本次标签源码，按[鸿蒙开发 README](https://github.com/2877905731/Innocence/blob/v1.2.3-harmonyos-preview.1/client/flutter_app/harmonyos/README.md)准备锁定的 Flutter OH 与 DevEco 26 工具链；本工程脚本按用户要求使用 F 盘。
2. 在 `client/flutter_app` 运行 `./tool/harmonyos.ps1 -Action build -Unsigned`；x64 模拟器加 `-Architecture x64`。这两条命令用于生成未签名预览包。
3. 要在实体平板调试，请用 USB 连接平板，由设备使用者开启开发者调试并亲自处理电脑连接授权。在 `./tool/harmonyos.ps1 -Action ide` 打开的工程里配置自动签名；仅登录 DevEco 不会自动补齐设备 Profile。
4. 签名配置就绪后，运行 `./tool/harmonyos.ps1 -Action build` 生成签名调试 HAP，使用 DevEco/HDC 部署到 Profile 对应设备。签名密钥、Profile 与设备标识仅在本机保管。

[华为申请调试 Profile 文档](https://developer.huawei.com/consumer/cn/doc/doccenter-getting-started/agc-help-debug-profile-0000002248181278)说明调试 Profile 需关联调试证书与已注册设备；[华为开发入门说明](https://developer.huawei.com/consumer/cn/develop-novice-guide/)说明实体设备运行需要应用签名。正式应用市场分发另需发布签名及平台发布流程。

Windows/Android 正式版仍为 [v1.2.3](https://github.com/2877905731/Innocence/releases/tag/v1.2.3)，本预览不改变其正式下载资产。
