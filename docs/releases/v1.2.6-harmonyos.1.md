## 安装方式

1. 在自己的开发者账号中准备与设备和包名匹配的有效证书／Profile。包名为 `com.innocence.tablet.innocence_flutter`。
2. 在本机使用原密钥和匹配 Profile 签名；有旧应用时先核对应用身份、Debug／Release 和覆盖兼容性。
3. 通过官方 DevEco／HDC 安装签名后的 HAP，覆盖时保留旧资料，不卸载试错。

指定设备网页分发需合资格账号、指定设备发布 Profile、签名 HAP／描述、同域 HTTPS 及华为浏览器 Deeplink。它与“下载 HAP 后点文件直装”是两条不同体验；重新签名或换后缀不能把公开 HAP 变成 Android APK 式直装文件。[详细安装说明](https://github.com/2877905731/Innocence/blob/v1.2.6-harmonyos.1/client/flutter_app/harmonyos/INSTALL.zh-CN.md) · [官方 Deeplink 规范](https://developer.huawei.com/consumer/cn/doc/doccenter-submission/agc-help-internal-test-release-app-0000002260691994)

## 校验与边界

ARM64 Release/AOT 构建 209.0 秒（含依赖解析），版本／tablet／非 Debug／无 INTERNET、ZIP CRC、三份 ARM64 ELF、五份字体许可资源及 119 个 Dart 文件逐字节通过。官方 SDK 明确返回没有 HAP 签名块；这项结果确认未签名边界，不计验签成功。仓库源签名配置为空，暂存工程的私人配置保持原样但本轮显式使用 `--no-codesign`，未随 HAP 分发。

本轮源码分析无问题，指定 HarmonyOS 目标 13 项回归通过。实体平板新 Release 的安装／覆盖／资料恢复、字体与光场画面、完整输入／性能和 H5/G01 继续待验。TIMER／代理提醒仍需应用权益，后台只预排接下来 8 阶段，Flutter 冻结时不能承诺无限动态阶段接力。
