# Innocence v1.2.3 鸿蒙平板本机版

用户已在自己的 HarmonyOS 7 平板上验收 `1.2.3+8` 设备调试版本，并明确授权沿用 GitHub 发布流程。本次公开分发 **ARM64 Release / AOT 未签名 HAP**，应用内版本仍为 `1.2.3+8`。

**公开下载包需要接收者配置自己的设备 Profile 并签名后安装。** 用户已安装的调试签名包绑定其个人平板，只在本机保存，不包含在公开资产中。Release 是编译模式；本次没有提供面向全部设备的发布证书，也没有上架华为应用市场。

平板使用 PC 完整侧栏和工作台，横屏/反向横屏全屏，关闭 Windows 窗口控制、拖边、托盘和 Focus Orb。保留四主题与当前本机计划、专注、统计、备忘录和设置逻辑。此版本强制本机模式，**包内不声明 INTERNET 权限**；登录、云同步、社交和模型联网调用继续后续接入。

本轮新增独立 Release 暂存目录和构建参数，设备调试签名工程保持原样。鸿蒙全屏模式在首帧之后设置，原生 Flutter 宿主扩展系统安全区，修正 Release 启动时顶部留出系统区域的问题；键盘安全区仍由现有逻辑处理。

源码分析无问题；10 项平板布局/离线入口回归通过。ARM64 原生 Release 构建成功，ZIP CRC、版本、横屏 tablet、兼容 SDK `5.1.0(18)` / target `26.0.0`、Flutter/SQLite/libapp 的 ARM64 ELF、AOT 库和无 JIT kernel、113 个共享 Dart 文件及原生宿主源码一致性通过。公开包经官方 SDK 确认为未签名，包内没有设备标识与签名材料。

作为 Release 运行核对，私有 x64 构建已在 API 26 平板模拟器安装、启动及进程冷启动，App 范围/截图为 `2800×1840`，可见 PC 简约白首页；当前 PID 的 Flutter 致命异常和布局溢出筛选均 0，输入法 `12800008/12800009` 仍有 2 条。x64 包仅用于本轮核对，不作为 ARM64 平板下载资产。

真机证据来自此前设备签名 Debug 包的安装、启动和用户本人验收；**此次 ARM64 Release 包未重新安装到用户正在使用的平板**。业务数据保存/覆盖升级/冷启动恢复、完整输入/触控/性能及负向路径继续按实际证据推进，不以本次分发关闭完整 H5/G01。兼容 SDK 下限不表示所有 API 18 设备均已验证。

## 构建和设备签名

1. 获取 `v1.2.3-harmonyos.1` 标签源码，按[鸿蒙开发 README](https://github.com/2877905731/Innocence/blob/v1.2.3-harmonyos.1/client/flutter_app/harmonyos/README.md)准备锁定的 Flutter OH 和 DevEco 26。工具、缓存、产物和签名材料按本工程约定存放在 F 盘。
2. 在 `client/flutter_app` 运行 `./tool/harmonyos.ps1 -Action build -BuildMode release -Unsigned`，生成本次未签名 Release HAP；使用独立 `build/harmonyos-h0/app-release` 工程。
3. 需要在自己的平板调试时，由设备所有者开启 USB 调试并亲自完成电脑连接授权。运行 `./tool/harmonyos.ps1 -Action ide -BuildMode release`，在官方 IDE 配置与自己设备匹配的签名/Profile；源工程不保存真实签名配置。
4. 配置就绪后运行 `./tool/harmonyos.ps1 -Action build -BuildMode release`，使用 DevEco/HDC 安装与 Profile 对应的签名包。密钥、密码、Profile 和设备标识只保存在本机，不上传 GitHub。

[华为调试 Profile 文档](https://developer.huawei.com/consumer/cn/doc/doccenter-getting-started/agc-help-debug-profile-0000002248181278)说明调试 Profile 关联调试证书和注册设备；[华为应用分发说明](https://developer.huawei.com/consumer/cn/distribute/)介绍 AppGallery Connect 的正式分发流程。通用正式签名及应用市场发布需另行完成对应流程。
