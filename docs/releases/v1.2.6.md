# Innocence v1.2.6 · Android UI 更新

应用版本 `1.2.6+11`，重新发布已修正字体和玻璃光束的 Android 版本；鸿蒙在[独立发行页](https://github.com/2877905731/Innocence/releases/tag/v1.2.6-harmonyos.1)。Windows 下载继续使用 [v1.2.5](https://github.com/2877905731/Innocence/releases/tag/v1.2.5)。

## 更新内容

- 侘寂展示字内置 Crimson Text Regular／原生 Italic 和完整 Noto Serif SC 中文字体，标题、每日标语及品牌使用真实字形，附上游 OFL 许可。避免 Android／鸿蒙依赖不存在的 Georgia／serif 字族而回退成普通字。
- 液态玻璃三条光束保留原配色和轨迹，改用连续高斯羽化；纹理按像素密度生成，最长边 2048，配合重采样改善光束轮廓和折射边缘。
- 独立番茄、专注、计划、统计和本机持久化逻辑保持；没有新增数据库迁移或网络权限。
