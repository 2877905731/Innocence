# Innocence v1.2.4

整合全平台番茄闹钟分页、专注系统提醒、Android 离线专注兼容修复及鸿蒙竖屏适配。Windows / Android 版本为 `1.2.4+9`；鸿蒙在[独立发行页](https://github.com/2877905731/Innocence/releases/tag/v1.2.4-harmonyos.1)提供未签名 Release 本机包。

## 更新内容

- 专注页增加“专注计时 / 番茄闹钟”分页。专注开始后可设置学习和休息时长、绑定或解除番茄；修改时长从新的学习阶段开始，保留总计时、暂停状态和已完成次数，相同设置重复保存不重置。
- Android 通知栏同时显示总专注与番茄阶段倒计时。系统闹钟负责学习/休息阶段更新；暂停冻结、继续恢复，解除绑定移除番茄通知，总专注结束清理运行通知并提示完成。通知与精确闹钟授权状态在应用中明确显示。
- 计时按实际经过时间追赶前后台状态；Windows 沿用托盘驻留并增加自然完成系统气泡，提前结束不发完成提醒。
- 移除开始离线专注对 SQLite JSON 扩展的依赖；本机数据库自动从 v6 升级到 v7，保存番茄有效时长锚点和完成基数，设置与同步队列保持原子一致。
- 鸿蒙支持自动横竖屏，PC 工作台按内容宽度重排；新增专注/番茄通知与实况窗适配及能力提示，具体权益与后台限制见独立发行说明。
- 服务端新增当前用户番茄配置接口与离线导入兼容。已有服务端必须先应用[数据库迁移](https://github.com/2877905731/Innocence/blob/v1.2.4/server/innocence-server/src/main/resources/migrations/20261012-focus-pomodoro.sql)再部署。本次只发布源码与客户端包，没有部署后端。
