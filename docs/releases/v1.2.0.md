# Innocence v1.2.0

本次发布双端视觉更新，并首次提供正式签名的 Android 本机离线版。

## 下载文件

- `Innocence-v1.2.0-windows-x64-setup.exe`：Windows x64 安装器。
- `Innocence-v1.2.0-windows-x64-portable.zip`：Windows x64 便携包，解压后运行 `innocence_flutter.exe`。
- `Innocence-v1.2.0-android-offline.apk`：Android 7.0+ 本机离线 Release APK，包含 ARM 32/64 位与 x86_64。
- `SHA256SUMS.txt`：上述文件的 SHA256 校验值。

## 本次变化

- 简约白色与液态玻璃视觉覆盖双端，包含柑橘点缀、独立磨砂浮窗、动态空间光、玻璃折射和统一的二级弹层。
- Android 使用三点按钮侧边栏，本机资料在明确选择离线模式后可冷启动恢复。
- Android 短计划改为 24 小时圆盘选段，支持点选起止、拖动边界、半小时微调及输入校验；凌晨为 `00:00`，当天结束为 `24:00`。
- 玻璃态年度月份栏使用中性磨砂材质；手机编辑内容可滚动，保存固定在底部。
- Android 应用名和图标统一为 Innocence，使用独立发行签名。

## Android 使用范围

首次进入选择语言并确认本机离线模式，无需服务器。可使用短计划、专注、统计、备忘录与本机设置。本包关闭联网请求，并移除 `INTERNET` 权限；登录、好友、团队、聊天、云同步与推送后续接入。时间段仍为同一天 `00:00–24:00`，不包含跨日计划。

资料保存在设备上，卸载或清除应用数据会移除本机资料。此前开发 Debug APK 与正式发行签名不同，不能直接覆盖安装；请先妥善保留已有开发版数据。后续正式更新将沿用同一发行签名。

## 验证与后续事项

Flutter analyze 无问题，93 项全量用例和 8 项离线编译／恢复专项通过。双端 Release 产物由打包脚本校验版本、校验值与包结构；Android 另校验正式签名、非调试状态和无联网权限。

Android 16／API 36 独立模拟器在飞行模式下完成安装、语言与离线入口、圆盘凌晨／午夜边界、短距离拖动、计划保存、专注启动／暂停／结束及备忘录保存核对。同签名覆盖安装并冷启动后，两段计划和备忘录保留，两主题切换及玻璃页面可见；本轮最终进程日志筛选无 Flutter 致命异常或布局溢出。

Windows 安装器尚无 Authenticode 签名，系统可能提示未知发布者。实体 Android 手机、完整月／年计划手机布局、长期前后台与性能，以及 Windows 多尺寸／多 DPI 和真实跨设备同步仍待进一步验收。
