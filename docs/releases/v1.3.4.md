# Innocence v1.3.4 · 在线账号更新与统一番茄入账

应用版本 **1.3.4+16**，Windows x64 与 Android 联网版。鸿蒙平板见 [v1.3.4-harmonyos.1](https://github.com/2877905731/Innocence/releases/tag/v1.3.4-harmonyos.1)。

## 更新内容

- 恢复开始专注时绑定番茄，可自定义每轮学习与休息。总专注窗口包含休息和等待，只有实际番茄学习片段计入学习时间，不再把总窗口重复累计。暂停、继续和结束共用一套控制。
- 学习到点立即停下并通知，手动开始休息；休息到点通知并完成一轮，再手动开始下一轮。后台恢复只结算当前阶段，总窗口结束截断计时。
- 新增后台“版本发布”：在本机编译并签名，上传安装包保存草稿，核对后发布或下架。服务器负责版本信息、校验及向在线账号传输，不承担编译。
- 在线账号在“设置 → 关于与维护 → 软件更新”检查新版本、下载并校验 SHA256。Windows 校验安装器版本后打开 Inno 安装器，Android 校验包名、构建号及原签名后打开系统安装器；均需用户确认。有计时任务时阻止安装，离线模式隐藏更新入口。
- 下载支持断点续传，账号切换丢弃下载状态；安装前重新确认会话、发布状态和包摘要。未登录、过期会话、错误平台、未发布/下架版本不能从服务器下载。
