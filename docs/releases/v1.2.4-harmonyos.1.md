# Innocence v1.2.4 鸿蒙平板本机版

整合自动横竖屏、专注系统提醒与独立番茄闹钟分页，应用版本为 `1.2.4+9`。本页分发 **ARM64 Release / AOT 未签名 HAP**；公开包需要接收者配置自己的设备 Profile 并签名后安装。个人设备签名包、证书和 Profile 只在本机保存，不包含在公开资产中；没有上架华为应用市场。

## 更新内容

- 平板允许自动横竖屏，复用四主题 PC 全屏工作台，按实际内容宽度重排。Windows 窗口控制、拖边、托盘和 Focus Orb 不在平板启用。
- 专注页增加“专注计时 / 番茄闹钟”分页，专注开始后可设置、绑定或解除番茄，保留总计时、暂停状态与已完成次数；本机 SQLite 自动升级至 v7。
- 接入专注代理提醒、总计时与番茄独立 TIMER 实况窗及明确的能力提示。实况窗/代理权益未开通时普通通知仅显示快照和结束时间；需要自己的应用权益与 Profile 才能核对实际系统能力。后台连续番茄阶段接力尚待验证，当前不承诺该能力。
- 保持本机离线范围，包内不声明 INTERNET 权限。登录、云同步、社交、模型联网、原生保险库与设备槽位继续后续接入。

## 构建与签名

1. 获取 `v1.2.4-harmonyos.1` 标签，按[鸿蒙开发 README](https://github.com/2877905731/Innocence/blob/v1.2.4-harmonyos.1/client/flutter_app/harmonyos/README.md)准备锁定的 Flutter OH 和 DevEco 26；工程工具、缓存、产物和签名材料存放 F 盘。
2. 在 `client/flutter_app` 运行 `./tool/harmonyos.ps1 -Action build -BuildMode release -Unsigned`，使用独立 `build/harmonyos-h0/app-release` 工程。
3. 设备所有者亲自完成 USB 调试授权，并通过 `./tool/harmonyos.ps1 -Action ide -BuildMode release` 在官方 IDE 配置自己的证书、Profile 和设备；实况窗/代理提醒权益需按自己应用接入。
4. 配置就绪后运行 `./tool/harmonyos.ps1 -Action build -BuildMode release` 生成对应签名包。密钥、密码、Profile 和设备标识留在本机，不上传 GitHub。
