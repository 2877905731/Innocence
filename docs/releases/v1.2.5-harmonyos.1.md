# Innocence v1.2.5 鸿蒙平板本机版

应用版本 `1.2.5+10`。新增可直接开始、暂停、继续、结束的独立番茄闹钟，与总专注分别控制，总专注结束后继续。设置、暂停进度和完成数按当前身份保存在本机；重开追赶当前阶段，SQLite 自动升级到 v8。原有专注绑定记录保留。

公开 ARM64 Release/AOT HAP **未签名**，无 INTERNET 权限；接收者必须配置自己的设备 Profile 并签名。没有上传个人设备 Profile、证书、私钥或单设备签名包。不是华为应用市场发行。

## 系统提醒范围

独立实况窗 TIMER、普通快照和阶段提醒与总专注使用不同 ID。代理服务预排接下来 8 个阶段，回到应用续排；受系统配额及应用权益控制。Flutter 冻结时 Live View 不能自行更新为下一阶段，代理提醒会显示对应阶段和结束时间。缺少权益时普通通知只是快照，请保持应用前台。界面会提示实际能力不足；不把这项有限预排当无限后台动态接力。

ARM64/x64 Release/AOT 构建、包 CRC/ELF/版本/无 INTERNET、空签名配置、118 个 Dart 文件与原生宿主逐字节及 SDK 未签名核验通过；10 项平板回归和全量客户端回归通过。本次未在用户实体平板重装新 Release；输入/性能、真机升级与完整 H5/G01 继续待验。
