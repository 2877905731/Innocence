# Innocence v1.3.0 · Windows、Android 联网版

应用版本 **1.3.0+12**。Windows 与 Android 现在可连接已部署的 Innocence 服务，使用邮箱账号登录、读取服务器资料与计划，并在确认后导入本机资料。鸿蒙平板联网包单独提供在 [v1.3.0-harmonyos.1](https://github.com/2877905731/Innocence/releases/tag/v1.3.0-harmonyos.1)。

同一账号可同时登录 **一台 Windows、一台 Android、一台鸿蒙平板**。三类设备各有独立名额；同类新设备登录只替换该类的旧会话。管理网页使用独立会话，通过原 SSH 隧道访问。

## 下载与安装

- Windows 安装版：`Innocence-v1.3.0-windows-x64-setup.exe`。
- Windows 便携版：`Innocence-v1.3.0-windows-x64-portable.zip`，完整解压后运行程序。
- Android：`Innocence-v1.3.0-android-online.apk`，沿用原发行证书，可交系统安装器覆盖旧版，保留应用资料。
- `SHA256SUMS.txt` 提供以上文件的 SHA-256 校验值。

请直接覆盖更新，保留原应用和数据目录。Windows 安装器未购买代码签名证书，系统可能显示发布者未知。旧离线发行版本仍可在历史 Release 下载。

## 联网与本机资料

联网包内置生产 HTTPS 地址，不需要用户填写服务器地址。服务器从空库开始，没有迁移本机账号或资料；需要使用服务器上正常注册的邮箱账号。登录后，导入预览会显示目标账号；确认前不上传本机业务正文。未登录时仍可选择本机模式。

AI 聊天助手继续使用用户自行配置的模型服务地址和 API Key。部署后端不会自动提供模型额度，真实供应商的模型发现、对话和工具能力仍取决于该服务。连接配置保存在当前设备的加密仓储，不同步模型密钥。
