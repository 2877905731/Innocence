# Innocence v1.3.0 鸿蒙平板 · 联网版

应用版本 **1.3.0+12**，ARM64 Release/AOT，设备类型为平板。此版本启用网络权限，内置生产 HTTPS 服务地址，支持邮箱账号登录、服务器资料与计划、本机资料确认导入，以及独立的平板会话名额。

同账号允许一台 Windows、一台 Android 和一台鸿蒙平板同时在线；新平板登录只替换旧平板会话。全屏 PC 页面、自动横竖屏、本机离线入口和既有四主题继续保留。

## 下载与安装

- `Innocence-v1.3.0-harmonyos-arm64-online-release-unsigned.hap`：**公开包未签名**，需接收者使用自己的有效证书和设备 Profile 签名，再经 HDC 安装。
- `HARMONYOS-RELEASE-README.md`：安装和更新说明。
- `SHA256SUMS.txt`：上述文件的 SHA-256 校验值。

未签名 HAP 不能下载后直接点开安装。公开资产不含个人证书、私钥、设备 Profile 或设备绑定签名包。已有应用应沿用匹配的包名和签名身份覆盖更新，保留原资料；遇到签名不匹配先核对身份，不通过卸载解决。

## 模型密钥与资料

BYOK模型连接使用鸿蒙 HUKS AES-256-GCM 加密，密钥不导出、不上传 Innocence 服务器；完整连接按当前账号或本机身份分区。每次加密使用随机 nonce，篡改、未知格式或缺密钥时拒绝解密，不作明文保存。应用被卸载或密钥失效后需重新配置连接。

登录不会自动上传本机资料，仍先预览目标账号并确认导入。模型服务由用户自行提供，真实供应商发现、生成和工具调用尚需针对所填服务验证。

## 本次验证与范围

ARM64发行构建、网络权限、AOT/ZIP完整性、字体许可、共享源码一致性与公开包未签名状态已核对。宿主实际 HTTPS 登录/共享计划和三会话并存/同类替换通过。

独立 API26/x64 原生模拟器通过 HUKS 加密解密、随机 nonce、篡改/格式/空输入拒绝、进程重启后解密，以及系统信任的 HTTPS 健康访问和匿名401。用户连接的 LRT-W20 平板上，专用签名 Release 包经官方验签并安装成功；本人解锁打开后，应用进程和收件箱PC布局画面已核对。没有绕过锁屏或清除资料，个人包仅保留在本机 F 盘。

实体平板真实邮箱登录、全部业务交互、Release覆盖旧资料、长期性能，以及实况窗/代理提醒所需权益仍需继续验收。公开 HAP 不附带个人设备资格，正式 H5/G01 完整门禁保持开放。
