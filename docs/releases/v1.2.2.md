## 更新内容

- Android 计划入口新增“今日／月计划／年度”独立手机页面。月计划提供完整日历、单日详情与任务存档，可多选日期并选择跳过已有安排或确认覆盖后批量套用。
- 年度页面提供全年月份刻度、任务跨度、七色充能进度与独立子任务。进度保存于当前本机资料域。
- Android 版本名为 `1.2.2`，构建号为 `7`；正式 APK 保持原 applicationId 与发行证书，可覆盖 v1.2.1 并保留本机资料。此版本仍是本机离线版，不开放联网请求。
- Windows 提供 x64 安装器与便携包。安装器没有 Authenticode 签名。
