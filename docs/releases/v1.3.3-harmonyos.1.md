# Innocence v1.3.3 鸿蒙平板 · 计时、助手与主题封面更新

应用版本 **1.3.3+15**，ARM64 Release/AOT联网版，平板全屏PC布局并按横竖屏重排。Windows与Android见 [v1.3.3](https://github.com/2877905731/Innocence/releases/tag/v1.3.3)。

## 本次更新

- 自定义专注1–1440分钟；独立番茄每个学习/休息阶段到点停下并通知，等待用户手动开始下一阶段，休息结束完成一轮。学习时长入账，暂停/等待/休息及本机普通专注重叠时间不重复累计。
- 年度助手新建走正确创建接口，编辑保留原进度/子任务，失败回传原因和请求标识。新增多个可切换、可删除的对话，独立保存消息/草稿/模式并迁移旧历史；删除聊天保留业务任务。
- 侘寂、中世纪和液态玻璃以原创Innocence矢量字标作为封面主视觉，日更内容退为次要文字；内置字体、玻璃材质和四主题存储值保留。
- 使用生产HTTPS及独立tablet会话名额；模型连接继续按身份使用HUKS加密保存。学习入账与安全请求追踪后端已上线，原资料确认导入边界保留。

## 公开文件与安装

- `Innocence-v1.3.3-harmonyos-arm64-online-release-unsigned.hap`：**未签名公开包**。
- `HARMONYOS-RELEASE-README.md`：本说明及安装边界。
- `SHA256SUMS.txt`：HAP与说明文件的SHA256校验值。

接收者需使用自己的有效证书及设备Profile签名，再通过DevEco/HDC安装；未签名HAP不能下载后直接点开安装。已有应用应使用匹配的包名、应用标识和签名身份覆盖更新，保留资料，遇到身份不匹配先核对，不通过卸载试错。

公开文件不含个人证书、私钥、Profile、设备标识或绑定设备的签名包。本人平板已经安装的个人原签名1.3.3无需替换为此未签名包，个人签名材料继续仅存本机。
