# Innocence v1.2.1

本次发布修正 Android 的玻璃反射、圆盘触控和启动图标，并补齐双端每日标语。

## 下载文件

- `Innocence-v1.2.1-windows-x64-setup.exe`：Windows x64 安装器。
- `Innocence-v1.2.1-windows-x64-portable.zip`：Windows x64 便携包，解压后运行 `innocence_flutter.exe`。
- `Innocence-v1.2.1-android-offline.apk`：Android 7.0+ 本机离线 Release APK，包含 ARM 32/64 位与 x86_64。
- `SHA256SUMS.txt`：上述文件的 SHA256 校验值。

## 本次变化

- 修正 Android OpenGL ES 的玻璃纹理方向，使面板中的折射光场与页面背景正确对应。
- 扩大短计划圆盘首尾手柄的触控范围，按下手柄后立即接管拖动，减少误触页面上下滚动；半小时精度、防重叠与当天边界保持适用。
- Android 首页新增每日标语；Windows 在专注期间也持续显示每日标语，跨午夜或返回应用后刷新。
- 放大 Android 自适应图标的前景占比，改善系统轮廓内主体偏小的情况，保留完整品牌图案与字标。

## 升级与使用范围

Android 版本为 `1.2.1`，构建号为 `6`。沿用 v1.2.0 正式发行签名，可直接覆盖正式版保留本机资料。此前开发 Debug APK 使用不同签名，不能直接覆盖正式版。资料保存在设备上，卸载或清除应用数据会移除本机资料。

Android 继续提供本机离线版：短计划、专注、统计、备忘录与本机设置无需服务器。发布包关闭联网请求并移除 `INTERNET` 权限；登录、好友、团队、聊天、云同步和推送后续接入。计划时间段仍为同一天 `00:00–24:00`。

## 验证与后续事项

Flutter analyze 无问题，99 项全量回归和 8 项离线编译／恢复专项通过。双端 Release 打包校验版本、校验值与包结构；Android 另校验正式签名、非调试状态和无联网权限。

Android 16／API 36 隔离模拟器在飞行模式下从正式 v1.2.0 覆盖升级，冷启动后本机资料与原有 `05:30–09:00` 计划保留；每日标语、玻璃首页与放大的圆形图标可见。当前应用进程日志筛选未见 Flutter 致命异常或布局溢出。

Windows 安装器尚无 Authenticode 签名。Android 实体手机、OEM 启动器图标裁切、Vulkan 设备与长期性能，Windows 多尺寸／多 DPI 视觉及真实跨设备同步仍待进一步验收。
