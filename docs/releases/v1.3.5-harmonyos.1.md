# Innocence v1.3.5-harmonyos.1 · 鸿蒙平板任务排序

应用版本 **1.3.5+17**，ARM64 Release/AOT，全屏平板布局。Windows/Android见 [v1.3.5](https://github.com/2877905731/Innocence/releases/tag/v1.3.5)。

今日任务、年度任务及年度子任务新增“排序”，支持拖动手柄和上下箭头。年度按月筛选共用全年顺序，编辑草稿时也能调整；今日编辑器再次保存会保留手动顺序。排序保留时段、完成状态、年度月份/颜色/进度和子任务内容，时间轴仍按原时段绘制。

离线顺序持久保存；在线排序由当前账号的专用接口校验任务集合及版本，其他设备已修改时拒绝覆盖，保存失败保留草稿。原有专注/手动番茄、唯一学习入账、多对话和在线检查更新保留。
