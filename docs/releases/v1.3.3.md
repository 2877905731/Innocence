# Innocence v1.3.3 · 计时、助手与主题封面更新

应用版本 **1.3.3+15**，Windows x64 与 Android 联网版。鸿蒙平板单独提供在 [v1.3.3-harmonyos.1](https://github.com/2877905731/Innocence/releases/tag/v1.3.3-harmonyos.1)。

## 本次更新

- 专注时长支持直接输入1–1440分钟，保留快捷选项，到点结束并通知。
- 独立番茄按学习、等待开始休息、休息、等待开始下一轮学习运行。每个阶段到点停下并通知，不自动跨阶段；休息结束计为完整一轮。学习时长进入统计，暂停、等待和休息不计入；与本机普通专注重叠的时间不重复累计。
- 在线番茄记录按当前账号幂等上传，断网保留待补传；本机资料仍经导入预览与目标账号确认。学习入账后端及兼容迁移已上线。
- 修复AI助手联网新建年度任务误走更新接口的问题；编辑保留原进度及子任务完成状态。失败保留错误码、可读原因及请求标识，结果不明时不自动重复写入。
- AI助手支持新建、切换和删除多个对话，每个对话分别保存消息、输入草稿和聊天/操控模式。旧历史迁入新格式，按账号或本机身份隔离；删除对话不删除已经保存的软件任务。
- Windows/鸿蒙的侘寂、中世纪与液态玻璃封面改为原创Innocence矢量字标，日更标语退为次要文字；Android已开放的液态玻璃同步更新，并合并重复标语卡，仍保留简约白色/液态玻璃两主题入口。简约白品牌构图、Android原玻璃渲染和内置字体保留。
