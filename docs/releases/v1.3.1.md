# Innocence v1.3.1 · Android 液态玻璃恢复

Android 应用版本 **1.3.1+13**，联网版。

- 恢复 Android 液态玻璃在此前误改前的背景光束：原模糊、椭圆光晕、纹理尺寸和重采样方式。
- 保留侘寂主题的 Crimson Text 英文衬线、原生斜体与 Noto Serif SC 中文展示字体修正。
- 沿用生产 HTTPS 服务、三端独立会话和本机资料确认导入功能。

## 下载与更新

下载 `Innocence-v1.3.1-android-online.apk`，使用系统安装器覆盖正式旧版即可。APK沿用原发行签名，版本号递增；更新时保留原应用与数据目录。`SHA256SUMS.txt` 提供文件校验值。

本次发布Android修正版；[Windows v1.3.0](https://github.com/2877905731/Innocence/releases/tag/v1.3.0)和[鸿蒙 v1.3.0-harmonyos.1](https://github.com/2877905731/Innocence/releases/tag/v1.3.0-harmonyos.1)继续提供既有下载。
