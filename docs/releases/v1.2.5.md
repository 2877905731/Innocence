# Innocence v1.2.5

番茄闹钟现在可以独立计时。Windows、Android、鸿蒙版本均为 `1.2.5+10`，鸿蒙在[独立发行页](https://github.com/2877905731/Innocence/releases/tag/v1.2.5-harmonyos.1)提供未签名本机包。

## 使用方式

打开专注页面，切换“番茄闹钟”，设置学习和休息时长后点击“开始番茄闹钟”。无需先开始总专注；番茄有自己的暂停、继续和结束按钮，总专注结束后也会继续。自动循环学习/休息，休息设为 0 时连续学习；结束后可重新设置时长。

## 更新内容

- 纠正 v1.2.4 只有独立分页、仍依附总专注的问题。新增独立时钟、本次完成次数及系统通知开关；原有专注绑定记录保留兼容，可单独解除。
- 暂停保留进度；切换页面不停止，后台返回或重开应用按实际时间恢复。SQLite 自动升级 v7→v8，已有计划、备忘录与专注保留；独立时钟按当前身份隔离，只在本机保存，不重复计入专注统计、不自动签到。
- Android 独立系统倒计时和阶段提醒；原生闹钟负责阶段切换，与总专注通知分离。总专注结束不会清除番茄，暂停/继续/结束和通知权限不足均有对应处理。
- Windows 托盘驻留时在学习/休息切换发送系统气泡，完全退出期间不发送气泡，重开恢复当前阶段。
- 鸿蒙独立 TIMER/普通通知与阶段代理提醒，能力限制见下文。没有新增服务器接口，也没有线上迁移或部署。
