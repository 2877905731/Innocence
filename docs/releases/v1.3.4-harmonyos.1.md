# Innocence v1.3.4-harmonyos.1 · 鸿蒙平板联网版

应用版本 **1.3.4+16**，ARM64 Release/AOT，全屏平板布局。Windows/Android见 [v1.3.4](https://github.com/2877905731/Innocence/releases/tag/v1.3.4)。

恢复开始专注时绑定手动番茄，学习/休息可自定义；只有实际学习片段入账，总专注窗口不重复计时。学习结束停止并通知，手动开始休息；休息完成通知后完成一轮，再手动开始下一轮。暂停、继续、提前结束和总窗口截断联动，等待和休息不计入学习。

新增在线账号的软件更新检查、鉴权下载和摘要校验/导出。后台在本机编译后上传并发布，由服务器传输。**当前指定设备开发分发没有通用的应用内安装资格**，下载的公开包需由接收者使用自己的有效证书及设备Profile签名，再通过电脑/DevEco/HDC覆盖安装；未签名HAP不能直接点击安装。
