# 简约白表盘与首页视觉验收

用户截图指向首页专注卡右侧圆球、顶部标语卡右侧半遮挡圆球和“每日标语”标签。按最新指令替换这些呈现，并在双端移除标签、保留正文；用户原文完整保存在UI设计规划的DEC-0053节。

## 实际改动

- FocusTimerDial读取现有FocusSession：黑色分针和橙色秒针表达已用时间，外圈表示已用/计划时长，下面显示已用时间或暂停/待开始/已结束状态。数字倒计时与表盘共用SessionController原一秒ticker，不创建独立Timer或循环装饰动画。暂停冻结、继续推进；提前结束保留实际进度，正常结束完成，重新开始归零。
- 桌面首页及专注页用表盘替换静态圆球，宽屏位于时间右侧，窄屏/大字体改上下布局避免遮挡正文。手机首页摘要及专注页复用该表盘，业务按钮与原回调继续工作。
- 顶部右侧和手机欢迎卡使用CitrusStepArtwork：橙色阶梯、斜线纹理、炭黑方向线与中性网格，完整可见；仅是装饰，排除读屏语义，不冒充业务图表。宽屏文字/图形分区，窄屏按内容重排。
- WhiteSurfacePanel采用实色白、清晰中性边线及柔影；简约白普通卡片也加强边界。暖灰画布保持原值，不通过磨砂遮挡图形。旧CitrusFocusDisc与WhiteFrostedPanel已从活动源码删除/替换，玻璃等其他主题保留各自材质。
- 桌面品牌栏仅保留INNOCENCE；手机删除标签行。中英文“每日标语 / Daily inspiration”均不再显示，现有原创正文/副文案、日期主题语言池及专注时保留正文的规则继续生效。
