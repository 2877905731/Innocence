# 专注页番茄分页与通知

2026-10-12 用户要求全平台在开始专注后的页面增加独立番茄闹钟分页，并在手机通知栏显示绑定的番茄闹钟。

实现前范围与契约：

- Windows、Android、鸿蒙共享“专注计时 / 番茄闹钟”分页。番茄页设置学习 1–1440 分钟、休息 0–1440 分钟，显式保存后绑定当前活动 session；可以解除绑定。未开始时提示先开始专注。
- 首次绑定或改变时长，从保存时的有效专注秒数开始新的学习阶段；保留已经完成的番茄数、总专注起止时间、有效时长和暂停状态。相同配置重复保存不重置阶段。剩余总时长小于一个阶段时，以总专注结束为界。
- 新增 `POST /api/app/v1/focus/session/pomodoro`，Bearer 当前用户，必填 `sessionId`、`bindPomodoro`；绑定时必填上述两个时长。只能修改属于当前用户的当前活动/暂停 session，陈旧或其他用户 session 拒绝。返回完整 `FocusSession`。响应兼容新增 `pomodoroElapsedOffsetSeconds`、`pomodoroCompletedBaseCount`，旧数据默认 0。
- SQLite v6→v7 增加有效秒数锚点与已完成基数两列，保留现有资料；结束行单独保存最终数量。离线设置与 outbox 在同一事务，新增 `pomodoro` 导入操作携带锚点与基数，仍必须经原有目标账号确认/绑定。同一专注的 outbox 递增 `clientVersion`，同时间戳按版本排序，保证创建、设置和结束顺序。
- Android 保留总专注通知，额外显示番茄阶段、轮次及系统倒计时；系统闹钟在阶段切换后更新番茄通知，暂停冻结，继续恢复，解除/结束/身份切换同时清除。鸿蒙通知和实况窗加入当前番茄阶段与剩余值，沿用既有权益能力提示；真实设备权益缺失不能计为动态通知完成。
- 原生桥接兼容旧未绑定载荷；绑定时严格校验阶段、时长和截止点，通知不包含任务名、身份或凭据。阶段切换不自动签到或完成任务。

验证命令、结果、产物与待验设备范围在本轮检查点记录。不自动推送、部署后端或替换公开发行。

鸿蒙番茄实况窗使用独立 TIMER ID，原总计时保留；不可用时独立普通通知显示阶段、轮次、剩余快照及阶段结束时间。普通通知不是动态倒计时。应用计时推进时会同步新阶段；后台/进程回收后的连续阶段自动接力尚需系统能力及设备验收，当前仅总专注结束沿用代理提醒。原真机权益仍未开通，不将代码和编译成功计作真机动态效果。

线上服务需要先应用 `server/innocence-server/src/main/resources/migrations/20261012-focus-pomodoro.sql` 再部署。客户端离线版已自带 SQLite 自动升级；本轮没有修改真实线上数据库或发布后端。
