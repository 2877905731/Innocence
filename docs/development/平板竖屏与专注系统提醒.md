# 平板竖屏与专注系统提醒

2026-10-11 用户要求鸿蒙平板竖屏、Android/平板开始计时后在通知栏显示倒计时，并核查各端到点通知。实现前核对：鸿蒙 `auto_rotation_landscape` 锁横屏；三个宿主均未接专注完成系统提醒，应用通知收件箱与 Windows 托盘菜单不等于此能力。

本轮范围与契约：

- 鸿蒙允许自动横竖屏。复用 PC 导航及完整业务页，以实际内容宽度重排双列与指标，保持旋转时导航、计时与草稿；键盘高度变化不切换手机 Shell。
- 统一 `innocence/focus_notice` 原生适配，Windows 完成提醒复用桌面通道。通知只绑定当前本机/登录身份的当前专注；切换身份、提前结束及暂停必须取消旧系统提醒。暂停显示冻结值，继续按新结束时间重新安排。
- Android 用系统 Chronometer 显示倒计时、AlarmManager 与非导出的 receiver 提醒。通知权限由用户选择；Android 12+ 精确闹钟需要系统授权，未授权时明确提示可能延迟并提供设置入口，不宣称锁屏准点。无需后台循环或联网权限。
- 鸿蒙用系统代理倒计时负责后台/进程回收后的完成提醒。每秒动态通知使用 Live View Kit TIMER 场景，取决于华为场景准入；普通通知的 `isCountDown` 在所用 SDK 标记未支持，不能将其作为可用实现。实况窗不可用时显示当前快照及结束时间，并明确动态倒计时未生效，不谎报成功。
- Windows 进程运行或托盘驻留时通过系统通知区气泡提醒；真正退出进程后不承诺提醒。自然完成提醒一次，提前结束不发完成提醒。
- Flutter 时间推进按快照时间与实际经过时长计算，补前后台恢复，保留暂停和番茄阶段语义。原生提醒不代替业务事务，也不自动签到或完成任务。
- 到点提醒正文使用通用文案，不显示任务名、用户身份或凭据；通知状态只在本机保存。此本地计时提醒独立于原云端通知收件箱及联网推送设置，不修改 HTTP/槽位/同步契约。

技术依据：[Android 系统闹钟](https://developer.android.com/develop/background-work/services/alarms)、[华为代理提醒](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides-V5/agent-powered-reminder-V5)、[华为实况窗场景说明](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides-V13/liveview-introduction-V13)。实现以本机 API26 SDK 类型与原生编译为准。
