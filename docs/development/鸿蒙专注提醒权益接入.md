## 2026-10-12 真机回执与接入材料

用户已保存草稿并明确允许覆盖安装和重启。本轮 ARM64 Debug 候选经过官方 SDK 验签、单设备绑定核对后覆盖安装启动成功，本机资料和液态玻璃主题恢复；用户确认竖屏自动重排正常。用户开始真实专注并保持页面后，安全调试回执与同进程 `FocusNotice` 日志一致：

```json
{"status":"backgroundAndLiveUnavailable","backgroundError":1700002,"liveError":"1003500005"}
```

`1003500005` 在本机 API26 SDK 明确对应 `The right of liveView is not enabled`。SDK 验签后的当前 Profile 只在内存中检查，未包含 `com.huawei.service.liveView.entry` 或 `com.huawei.service.push.base_service`。因此当前真机固定通知是回退快照，不能算实时显示。客户端将权益缺失独立映射为 `liveCountdownRightsRequired` / `backgroundAndLiveRightsRequired`，提示需要为应用开通权益。[实况窗场景及开发准备](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides-V13/liveview-introduction-V13)

`1700002` 表示代理提醒额度受限。独立模拟器同样返回该码，当前应用有效代理提醒数为 0；单靠这个数字不能确定所有应用总额度或审核状态。需要账号所有者核对代理提醒申请及授权。前台自然到点通知已经在独立模拟器收到，后台/进程回收后的到点保证仍未取得。[代理提醒指南](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides-V5/agent-powered-reminder-V5)

独立 API26 `.focusqa` 包的 TIMER 胶囊实际在系统桌面从 `00:53` 变为 `00:48`，两次截图间隔 5 秒；暂停时 57 秒和两个 `isPaused` 均冻结，继续后恢复，提前结束/旧截止点复读/身份清理与完成去重有系统收据。这个结果属于当前模拟器，不证明已获得真机权益或公开发行资格。

普通通知暂停不能传显式 `undefined`（真机 NAPI 返回 401），同一通知 ID 的更新还可能保留原自动删除计划。当前回退路径先取消旧通知，再以有效的 `autoDeletedTime=0` 发布冻结快照；运行时使用新的截止时间。独立 QA 可强制模拟权益缺失，核对暂停超过原截止点后通知仍在、没有误发完成，恢复及提前结束清理正确；正式应用不开放此 QA 控制入口。

最终独立QA收据：暂停剩余7秒后等待12秒，通知7312仍为1/7313为0；继续、提前结束和到点仅一次通过。包含此修正的最终ARM64候选已覆盖安装，首次启动被设备锁屏拒绝（10106102）；用户随后确认解锁并打开，最新进程存在，通用回执为`backgroundAndLiveRightsRequired`、Live1003500005/后台1700002。提示映射已生效，但原生UI抓取未取得对应提示文本，不补写界面验收。
