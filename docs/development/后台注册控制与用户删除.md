# 后台注册控制、用户删除与入口维护（0135）

2026-10-31用户要求：修复本机后台入口间歇不可达、后台控制是否接受注册、后台删除用户，并排查创建团队的服务端异常。当前入口仍为SSH隧道 `http://127.0.0.1:18080/`，公网管理路由保持既有配置。服务器、隧道静态200及无凭据管理401已核对；增加本机自动重连辅助，不能将本机回环地址当成其他设备可访问的网址。

## 注册开关契约

- 管理员 `GET /api/admin/v1/settings/registration`：返回 `{ enabled }`。
- 管理员 `PUT /api/admin/v1/settings/registration`：JSON `{ enabled: boolean }`，缺失或非布尔字段400；返回实际持久化状态。
- 默认接受注册，使用数据库单例行持久化；重启、重新部署不重置已有选择。读取失败不放行注册。
- 关闭时，公开 `POST /api/app/v1/auth/email/send-register-code` 和 `/auth/email/register` 返回403、code2001及“当前已暂停新用户注册，请联系管理员”。即使关闭前已取得验证码，关闭后也不能完成注册。
- 注册事务持有策略行共享锁；管理员关闭取得排他锁，关闭返回成功后新注册均被拒绝。已经开始且持锁的注册先完成，再提交关闭。
- 现有账号登录、密码找回及本机模式遵循原契约。管理员权限来自Bearer与邮箱白名单；普通用户不能读写管理开关。变更记录内部操作者ID、动作码和时间，不记录邮箱/密码/验证码。

## 删除用户契约

- 管理员 `GET /api/admin/v1/users/{id}/deletion-preview`：`{ userId, deletable, reason, ownedTeamCount }`，用于确认前显示实际影响。
- 管理员 `DELETE /api/admin/v1/users/{id}`：永久删除该服务器账号、认证/会话、业务资料、好友/黑名单关系及关联通知；返回 `{ userId, success, dissolvedTeamCount }`。用户不存在404；普通用户403；未登录401。
- 实现选择：管理员自己及白名单管理员账号不可删除；队长账号被删除时解散其拥有的团队并清理该团队成员关系与团队内容，其余成员的个人资料保留。普通成员只移除该成员及其相关记录。
- 页面在用户档案提供“删除用户”，显示对象及影响并确认一次；不会自动批量删除任何真实用户。服务端再次验证权限和目标，操作处于同一数据库事务，失败回滚；会话撤销后旧令牌无法继续访问。
- 事务提交后清理该用户受管头像，复用原头像路径边界；记录操作者/目标内部ID及动作码，不保存被删账号的身份信息或业务正文。既有私有备份按原部署保留，不作为在线账号。

## 团队错误

实际MySQL EXPLAIN确认：团队与队友统计的日计划子查询在 `daily_plan_item dpi JOIN daily_plan dp` 后使用无前缀 `user_id`，触发1052字段歧义。两个查询均改为 `dpi.user_id`，任务完成状态限定为 `dpi.status`；以实际MySQL和完整创建/加入/详情回归核对，不仅依赖mapper mock。
